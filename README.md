# User Profile Card 🌐

A sleek and responsive user profile card built using **HTML** and **CSS**. This project showcases personal information, contact details, and social media links in a compact, stylish format — perfect for portfolio sections, "About Me" pages, or resume sites.

---

## 🔧 Features

- Responsive layout for desktop and mobile screens
- Gradient header with profile photo
- Bio section with personal introduction
- Contact section with phone and email
- Social media icons with hover effects (Font Awesome)

---

## 🚀 Technologies Used

- HTML5
- CSS3
